        Модуль управления отчетами (Report Management)

#### Описание

Этот модуль предоставляет функциональность для управления отчетами. Он позволяет создавать, удалять, изменять, получать информацию об отчетах, а также выполнять различные запросы для фильтрации отчетов.

        Классы        
        
#### Класс Report 
Класс Report представляет собой модель данных для отчета.

#### Свойства
*   `Id`: `Guid` - Уникальный идентификатор отчета.
*   `Type`: `string` - Тип отчета (например, "Финансовый", "Аналитический").
*   `Content`: `string` - Содержание отчета.
*   `UserId`: `Guid` - Идентификатор пользователя, связанного с отчетом.
*   `CreationDate`: `DateTime` - Дата и время создания отчета.
*   `Status`: `string` - Статус отчета (например, "Завершен", "В процессе").

#### Класс ReportManager
Класс `ReportManager` предоставляет методы для управления отчетами (создание, удаление, обновление, получение).

#### Методы

*   `CreateReport(Report report)`: `bool` - Создает новый отчет. Возвращает `true`, если отчет успешно создан.
*   `DeleteReport(Guid reportId)`: `bool` - Удаляет отчет по ID. Возвращает `true`, если отчет успешно удален.
*   `UpdateReport(Report updatedReport)`: `bool` - Обновляет информацию об отчете. Возвращает `true`, если отчет успешно обновлен.
*   `GetReportById(Guid reportId)`: `Report` - Получает отчет по ID. Возвращает `null`, если отчет не найден.
*   `GetAllReports()`: `List<Report>` - Получает список всех отчетов.
*   `GetReportsByUser(Guid userId)`: `List<Report>` - Получает список отчетов, связанных с указанным пользователем.
*   `GetReportsByType(string reportType)`: `List<Report>` - Получает список отчетов указанного типа.
*   `GetReportCount()`: `int` - Получает общее количество отчетов.
*   `GetReportsByCreationDate(DateTime creationDate)`: `List<Report>` - Получает список отчетов, созданных в указанную дату (без учета времени).
*   `GetReportsByStatus(string status)`: `List<Report>` - Получает список отчетов с указанным статусом.

Модуль `ReportManagement` включает в себя набор автоматизированных тестов, разработанных с использованием фреймворка NUnit. Эти тесты расположены в классе `ReportManagerTests` в проекте `ReportManagement.Tests`. Они предназначены для обеспечения надежности и корректности работы класса `ReportManager` и охватывают следующие аспекты:
        
        Тестирование
•   **Создание отчета (`CreateReport`):**
Проверка успешного создания отчета с корректными данными. Тест должен убедиться, что метод `CreateReport` добавляет отчет в список и возвращает `true`.

•   **Удаление отчета (`DeleteReport`):**
 Проверка успешного удаления существующего отчета по его ID. Тест должен убедиться, что метод `DeleteReport` удаляет отчет из списка и возвращает `true`.

•   **Обновление отчета (`UpdateReport`):**
 Проверка успешного обновления данных существующего отчета. Тест должен убедиться, что метод `UpdateReport` изменяет свойства отчета и возвращает `true`.

•   **Получение отчета по ID (`GetReportById`):**
Проверка получения существующего отчета по его ID. Тест должен убедиться, что метод `GetReportById` возвращает корректный отчет, и что возвращается `null`, если отчет с указанным ID не существует.

•   **Получение списка всех отчетов (`GetAllReports`):**
 Проверка получения списка всех отчетов. Тест должен убедиться, что метод `GetAllReports` возвращает список, содержащий все созданные отчеты.

•   **Получение отчетов по пользователю (`GetReportsByUser`):**
Проверка получения списка отчетов, связанных с определенным пользователем. Тест должен убедиться, что метод `GetReportsByUser` возвращает только те отчеты, у которых `UserId` соответствует указанному.

•   **Получение отчетов по типу (`GetReportsByType`):**
Проверка получения списка отчетов определенного типа. Тест должен убедиться, что метод `GetReportsByType` возвращает только те отчеты, у которых `Type` соответствует указанному.

•   **Получение количества отчетов (`GetReportCount`):**
Проверка получения общего количества отчетов. Тест должен убедиться, что метод `GetReportCount` возвращает правильное количество отчетов в списке.

•   **Получение отчетов по дате создания (`GetReportsByCreationDate`):**
Проверка получения списка отчетов, созданных в определенную дату. Тест должен убедиться, что метод `GetReportsByCreationDate` возвращает только те отчеты, у которых `CreationDate` соответствует указанной дате (без учета времени).

•   **Получение отчетов по статусу (`GetReportsByStatus`):**
Проверка получения списка отчетов с определенным статусом. Тест должен убедиться, что метод `GetReportsByStatus` возвращает только те отчеты, у которых `Status` соответствует указанному.

(Также тест должен убедиться, что отчеты, которые не соответствуют фильтру, не возвращаются.)
